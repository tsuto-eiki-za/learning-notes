## `onKeyDown` イベント (2025/12/19)

キーボードのキーが押された瞬間に実行されるイベントハンドラ  
テキスト入力時に特定のキー(Enter キー)が押された時に処理を実行するみたいな使い方をする

- 入力が確定する前に発火される
- e.preventDefault() すると、そのキー入力自体をなかったことにできる
- `e.key`でどのキーが押されたかわかる

```tsx
<TextField
  onKeyDown={(e) => {
    console.log("押されたキー:", e.key);
  }}
/>
```

### `onKeyDown`を使うべき場面

- 特定のキー入力を検知したいとき

```tsx
// Enterキーで送信
onKeyDown={(e) => {
  if (e.key === 'Enter') {
    handleSubmit();
  }
}}
```

- デフォルトの動作を変更したいとき

```tsx
// 数字以外の入力を禁止
onKeyDown={(e) => {
  if (!/^[0-9]$/.test(e.key)) {
    e.preventDefault(); // 入力を止める
  }
}}
```

### LK で使った応用

初期値に「0」が入っている状態でキーボードから数値を入力しようとすると  
「010」のように 0 に続いて値が入力されてしまうバグ

```tsx
if ((assignment.number || 0) === 0 && /^[0-9]$/.test(e.key)) {
  e.preventDefault();
  handleCountChange(userId, e.key); // 自分で値を「1」に書き換える
}
```

- 今の値が 0 で、0~9 の数字キーが押された時に
- `e.preventDefault()`で「 0 の右に 1 が入る」動作をキャンセルして、
- 入力した値で書き換える

### Pagination

#### onPaginationModelChange

DataGrid のページ番号やページサイズが変わったときに呼ばれるコールバック

```tsx
onPaginationModelChange={(model) => {
  handlePaginationChange(model.page, model.pageSize);
}}
```

上記のコードの意味は、、

- `model`
  DataGridPro から渡される「現在のページネーション状態」のオブジェクト
  例: `{ page: 0, pageSize: 50 }`
- `model.page`
  現在のページ番号（0 始まりで 0,1,2,...）
- `model.pageSize`
  1 ページあたりの行数（10/25/50 など）
- handlePaginationChange(model.page, model.pageSize)
  ページ番号やページサイズが変わるたびに、
  あなたが定義した関数 handlePaginationChange に

  ```
  page = model.page
  newPageSize = model.pageSize
  ```

  を渡して呼び出しています。
